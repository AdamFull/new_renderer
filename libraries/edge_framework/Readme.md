# Edge Game Engine Framework

![Edge Logo](attachment:docs/images/logo.webp)

## About Edge
Edge is a powerful game engine framework focused on **speed of application deployment** and a **flexible graphical interface** that allows the implementation of almost any modern rendering technology.

## Key Features
- **Rapid Application Deployment**: Designed to minimize time from development to deployment.
- **Flexible Graphical Interface**: Supports integration of modern rendering technologies.
- **Development Support Systems**:
  - Memory management
  - Asynchronous operations
  - Custom file system
- **Integration with Well-Known Libraries**:
  - spdlog
  - tracy
  - And more...

## Why Choose Edge?
Edge empowers developers to build high-performance applications with efficiency, leveraging advanced tools and libraries to streamline the development process.
